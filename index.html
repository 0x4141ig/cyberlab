CEH v13 Quick Reference & Cheat Sheet

Key Nmap Scanning Parameters

FlagScan TypeDescription
-sSSYN Stealth ScanHalf-open scan; sends SYN, receives SYN/ACK, responds with RST. Default for root.
-sTTCP ConnectFull 3-way handshake (SYN, SYN/ACK, ACK). Used when raw sockets unavailable.
-sUUDP ScanScans UDP ports; no response = open|filtered; ICMP port unreachable = closed.
-sVVersion DetectionInterrogates open ports to determine exact application service & version.
-OOS DetectionAnalyzes TCP sequence predictability and window sizes for OS fingerprinting.
-AAggressive ScanEnables -O, -sV, -sC (default scripts), and --traceroute simultaneously.
-fFragmentationSplits IP packets into 8-byte fragments to evade simple packet inspection.
-DDecoy ScanMixes scan packets with spoofed decoy IPs (e.g. -D RND:5).
-g / --source-portSource Port SpoofingForces packets to originate from port 53 (DNS) or 80 (HTTP) to bypass firewall.

Windows nbtstat Utility Reference

CommandPurpose & Exam Note
nbtstat -A <IP>Displays remote machine NetBIOS name table using IP address (capital -A).
nbtstat -a <Name>Displays remote machine NetBIOS name table using Hostname (lowercase -a).
nbtstat -cDumps local NetBIOS Remote Name Cache (IP-to-NetBIOS name resolutions).
nbtstat -nLists Local NetBIOS Names registered by applications and services on host.
nbtstat -rDisplays names resolved via Broadcast vs. WINS Name Server.
nbtstat -RPurges and reloads the remote name cache table from LMHOSTS.
nbtstat -s / -SDisplays active NetBIOS Sessions table (client/server connection states).
